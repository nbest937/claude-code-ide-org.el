* Legend

  A worked example of every :LOGBOOK: convention this project uses, laid
  out as one complete cycle: define (09:00 clarify), plan (09:15
  PLANNING), implement (11:30), decide/refine (13:30), test (14:20),
  review (15:00), DONE (16:00). Entries read chronologically top to
  bottom for teaching purposes; org itself inserts newest-first, and
  consolidation may reorder — the meaning of each line, not its
  position, is the convention.

  - =CLOCK:= lines :: org's native intervals, always *inactive*
    timestamps, the sole arithmetic source of truth (=org-clock-sum=,
    clocktables, =org_clock_report=). Under the queue+review design
    (TODO.org =b5f7c5c7=) a CLOCK line exists only because a human
    confirmed it at review time — either drawn by hand from the
    guideposts below, or bulk-accepted from a mechanically-known agent
    interval (the 09:15 and 11:30 pairs here). Verify the ~=>  H:MM~
    arithmetic whenever editing one.
  - Active ranges (=<start>--<end> label=) :: guideposts — spans where a
    human was logged actually attending: clarifying (09:00), deciding
    (13:30), reviewing (15:00). Active timestamps surface in
    =org-agenda=, so the agenda doubles as a free retrospective "what
    did I actually attend to" view. Each typically sits beside the
    CLOCK line the human confirmed for the same span.
  - Inactive ranges (=[start]--[end] label=) :: unattended machine work
    (background planning agents, Claude implementation turns).
    Deliberately invisible to the agenda. The interval is mechanically
    knowable — an agent was either running or not — so review may
    accept a matching CLOCK line (09:15 planning, 11:30 implementation)
    or decline one (14:20 unit tests, which ran while the heading sat
    in WAIT); the annotation stays either way.
  - =- State "X" from "Y" [ts]= lines :: org's *native* state-change
    log, produced by =org-todo= running inside the interactive
    review-and-apply command with a backdated effective time — never
    hand-formatted, never suppressed with =org-inhibit-logging=. The
    =\\= continuation carries an optional note. The DOING → PLANNING →
    DOING arc (09:15/11:30) is the Plan Mode round-trip; WAIT → DOING
    (14:55) closes and reopens clocks around the blocked span.
  - Gaps :: honest absence of a record (09:30–11:30, 14:50–15:00).
    Nobody attended and nothing ran, so no line claims that time.
