# brainstorming

Inspired by and derived from the brainstorming skill of
[superpowers](https://github.com/obra/superpowers) by Jesse Vincent,
tag `v6.4.1` (commit `5bf4e78`), © 2025 Jesse Vincent, MIT License — see
[`LICENSE`](LICENSE). `.upstream` records the source.

The first commit to add this folder is the unmodified upstream copy; every
later commit to it is an adaptation for the claude-code-ide-org plugin.

`brainstorming-process-flow-adapted.html` renders the adapted skill's
Process Flow digraph from the `SKILL.md` in this folder. Upstream's, as
imported, was rendered too and removed; it is in this folder's history
(commit `99b9b54`).
