# `:CATEGORY:` values — this project's taxonomy

**This file is yours.** `claude-org-setup --org` created it once and
never regenerates it. It carries no `paths:` scope, so it loads in every
session: a heading is usually captured with no `.org` file open.

A value is a single capitalised word, and never a TODO keyword. A
top-level heading carries one in its own drawer; a child inherits it.

| value | what belongs here |
|---|---|
| `Meta` | meta-work: the `* Review and planning` datetree and the daily ceremony |

**Add a row before using a new value.** `org_capture` refuses a
top-level capture without a category and warns on a value the file has
never used; this table is where a value is declared and given a meaning.
